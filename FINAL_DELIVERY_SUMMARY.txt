🚀 立即可執行的上線步驟

1️⃣ 準備生產環境
   - 配置服務器 (Ubuntu 22.04)
   - 安裝 Node.js 18+
   - 安裝 PM2 進程管理器

2️⃣ 配置環境變數
   - 複製 .env.example 到 .env.production
   - 設置 ADMIN_JWT_SECRET
   - 設置 LINE Channel ID/Secret
   - 設置 Resend API Key

3️⃣ 部署應用
   - npm install --production
   - npx prisma migrate deploy
   - npm run build
   - pm2 start npm -- start

4️⃣ 上線驗證
   - 訪問登入頁面
   - 測試 LINE Login
   - 測試本地登入
   - 驗證 Session 創建
