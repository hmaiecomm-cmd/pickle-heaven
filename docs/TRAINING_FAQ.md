## 帳戶和登錄

### 🔐 登錄相關問題

#### **Q: 我忘記了密碼，該怎麼辦？**

**A:**

```
方法 1：自助重置（推薦）
  1. 進入登錄頁面
  2. 點擊「忘記密碼？」
  3. 輸入註冊郵箱
  4. 檢查郵件（檢查垃圾郵件文件夾）
  5. 點擊郵件中的重置鏈接
  6. 設定新密碼
  7. 使用新密碼登錄

時間：5 分鐘

方法 2：聯絡管理員
  • 發送郵件或電話聯絡管理員
  • 提供身份驗證信息
  • 管理員會為您重置密碼
  
時間：30 分鐘 - 1 小時
```

---

#### **Q: 登錄時顯示「帳戶已鎖定」，怎麼解決？**

**A:**

```
原因：您連續 5 次輸入錯誤的密碼

解決方案：
  1. 等待 30 分鐘（自動解鎖）
  2. 或點擊「帳戶已鎖定」旁的鏈接
  3. 輸入你的郵箱地址
  4. 查收解鎖郵件
  5. 點擊郵件中的解鎖鏈接

如果問題持續：
  → 聯絡 IT 支援：support@example.com
  → 電話：02-XXXX-XXXX
```

#### **Q: 我需要修改我的登錄郵箱地址？**

**A:**

```
自助修改（如果有權限）：
  1. 登錄後進入「我的帳戶」
  2. 選擇「設定」
  3. 找到「郵箱地址」
  4. 點擊「變更」
  5. 驗證舊郵箱（會收到驗證碼）
  6. 輸入新郵箱
  7. 驗證新郵箱（點擊郵件中的鏈接）
  8. 確認變更

如果無法自助修改：
  → 聯絡管理員
  → 提供身份驗證
  → 管理員會協助變更
```

#### **Q: 如何啟用雙因素認證 (2FA)？**

**A:**

```
步驟 1：下載應用
  建議應用：
  • Google Authenticator
  • Microsoft Authenticator
  • Authy

步驟 2：進入設定
  1. 登錄系統
  2. 進入「我的帳戶」→「安全性」
  3. 點擊「啟用雙因素認證」

步驟 3：掃描 QR 碼
  1. 在手機中打開身份驗證應用
  2. 點擊「+」或「新增帳戶」
  3. 選擇「掃描 QR 碼」
  4. 掃描頁面上顯示的 QR 碼

步驟 4：確認
  1. 應用中出現 6 位數字驗證碼
  2. 在頁面上輸入此驗證碼
  3. 點擊「確認」

步驟 5：保存備份碼
  1. 系統提供 10 個備份碼
  2. 保存在安全地方（密碼管理器）
  3. 遺失手機時可用這些碼登錄

之後登錄流程：
  • 輸入用戶名和密碼
  • 輸入手機應用中的 6 位驗證碼
```

## 排程和預約

### 📅 排程常見問題

#### **Q: 為什麼無法建立排程？**

**A:**

```
可能原因 1：迴路已被預訂
  症狀：顯示「此時間迴路已被預訂」
  解決：
    • 選擇其他迴路
    • 選擇其他時間
    • 選擇其他日期

可能原因 2：設備故障或離線
  症狀：迴路顯示為灰色
  檢查：
    • 點擊迴路查看故障詳情
    • 聯絡維護人員
    • 等待設備修復

可能原因 3：超過營業時間
  症狀：顯示「此時間超出營業時間」
  檢查：
    • 確認營業時間
    • 選擇營業時間內的時段
    • 如需特殊時間 → 聯絡經理

可能原因 4：權限不足
  症狀：按鈕呈灰色或無反應
  解決：
    • 檢查您的用戶角色
    • 聯絡管理員提升權限

可能原因 5：系統故障
  症狀：頻繁出現「服務暫時不可用」
  解決：
    • 刷新頁面（F5）
    • 等待 5-10 分鐘後重試
    • 清除瀏覽器快取
    • 聯絡技術支援
```

```
  4. 檢查衝突警告

  6. 確認費用計算

如果需要修改日期：
  1. 取消現有排程
  2. 建立新排程（新日期）
  3. 系統自動處理退款/收費
```

#### **Q: 批量排程如何操作？**

**A:**

```
什麼是批量排程？
  • 為同一客戶/群組建立多個排程
  • 一次性建立 2 個以上排程
  • 適合群組活動、公司活動

使用場景：
  • 公司團隊活動（多天多迴路）
  • 定期訓練班（每週相同時段）
  • 聯誼活動（多個迴路同時段）

建立步驟：
  1. 點擊「新增排程」→「批量」
  2. 選擇客戶/群組
  3. 選擇迴路數量
  4. 選擇日期範圍
  5. 選擇分配模式：
     ├─ 逐日（每天相同迴路）
     ├─ 輪轉（迴路循環）
     └─ 自訂（手動選擇）
  6. 預覽結果
  7. 確認建立

範例：
  客戶：ABC 公司
  迴路數：4
  日期：2026-11-20 至 2026-11-22
  模式：輪轉
  結果：12 個排程（4 × 3 天）

優勢：
  ✓ 節省時間（3 分鐘 vs 30 分鐘）
  ✓ 減少錯誤
  ✓ 自動計費
  ✓ 一次性取消
```

### 💳 預約和費用

#### **Q: 預約費用如何計算？**

**A:**

```
基本公式：
費用 = 迴路費率 × 持續時間（小時）× 客戶類別系數

費率表：
  迴路 01-09（標準）：NT$150/小時
  迴路 10-15（高級）：NT$200/小時
  迴路 16-18（VIP）：NT$250/小時

客戶類別系數：
  會員（年度）：× 0.8（打 8 折）
  會員（季度）：× 0.85（打 8.5 折）
  臨時客戶：× 1.0（原價）
  群組（10+ 人）：× 0.75（打 7.5 折）

計算範例：
  迴路 12（高級），1.5 小時，會員（年度）
  = NT$200 × 1.5 × 0.8
  = NT$240

特殊費用：
  清潔費：+NT$50（如需要）
  停車費：+NT$30（如適用）
  設備租賃：+NT$100-200（如需要）
  取消手續費：-10%（7 天內取消）

是否包含稅金？
  • 費用包含營業稅
  • 發票會分列稅金
  • 公司採購可申請發票
```

#### **Q: 如何取消預約？退款政策是什麼？**

**A:**

```
取消步驟：
  1. 進入「我的預約」
  2. 找到要取消的預約
  3. 點擊「取消」
  4. 確認取消（無法撤銷）
  5. 選擇取消原因（可選）
  6. 提交

取消何時有效：
  • 立即生效
  • 迴路立即釋放
  • 退款處理見下表

退款政策：

  取消時間            退款百分比        手續費
  ───────────────────────────────────────
  7 天前              100%             無
  4-7 天前            90%             10%
  2-4 天前            75%             25%
  1-2 天前            50%             50%
  活動開始後          0%              100%

退款範例：
  原費用：NT$240
  
  情景 1：活動前 10 天取消
    退款：NT$240 × 100% = NT$240
    手續費：無
    實收：NT$240
  
  情景 2：活動前 3 天取消
    退款：NT$240 × 75% = NT$180
    手續費：NT$240 × 25% = NT$60
    實收：NT$180

退款方式：
  ✓ 原付款方式退款（銀行卡/轉帳）
  ✓ 退款至系統帳戶（可用於後續預約）
  ✓ 兌換禮券（可選）

退款時間：
  • 銀行卡退款：3-5 個工作天
  • 系統帳戶：立即生效
  • 禮券：立即生效

無法取消的情況：
  ✗ 活動已開始
  ✗ 活動已完成
  ✗ 有場地損壞索賠
  ✗ 欠費未結清
```

#### **Q: 如何新增客戶？**

**A:**


#### **Q: 維護中和故障有什麼差別？**

**A:**

```
故障（紅色）：
  • 意外損壞或故障
  • 無法預測何時修復
  • 立即影響預約
  • 需要緊急維修

維護（黃色/藍色）：
  • 計畫性維護
  • 預先通知（通常 1 周）
  • 預約會被轉移或取消
  • 按排程進行
```
