## 三、資料庫 Schema 狀態

### 3.1 已存在的表
- **Device** — 設備清單
- **DeviceCommand** — 設備操作指令紀錄
- **Circuit** — 迴路資料
- **CircuitSchedule** — 迴路排程
- **CircuitScheduleAudit** — 排程修改審計
- **ControlCommand** — 電力控制指令
- **ControlEvent** — 控制事件紀錄
- **DeviceAdapter** — 設備適配器配置
- **其他**：Reservation, MaintenancePlan 等與預約排程相關

### 3.2 缺失的表（V8.1 需新增）
- **DeviceAlert / DeviceHealthAlert**：設備異常紀錄
  - 需記錄：異常類型、發生時間、嚴重度、處理狀態、維修記錄
  - 與 ControlEvent 的區別：ControlEvent 是系統事件日誌，DeviceAlert 是設備故障/警告紀錄

## 四、現有 API 與權限

### 4.1 已有 API
- `GET /api/admin/devices` — 獲取設備清單
- `POST /api/admin/control/command` — 發送控制指令
- `GET /api/admin/circuits/schedule` — 獲取排程
- `POST /api/admin/circuits/schedule` — 保存排程
- `GET /api/admin/automation/logs` — 排程執行日誌

### 4.2 RBAC 角色
- OWNER / MANAGER / OPERATOR / FRONTDESK / VIEWER / DEMO
- 權限檢查：device, device.control, device.automation, monitor, access 等
- **現況**：權限檢查已實裝在伺服器端
