## 測試場景 C：動畫與無障礙

### 場景 C1：動畫效能（Chrome DevTools Performance 標籤）

1. 選擇迴路 12（嚴重異常）使紅燈閃爍開始
2. 按 **F12** → **Performance** 標籤
3. 按紅色錄製按鈕，錄製 3 秒
4. 停止錄製

**檢查項目**
- [ ] FPS 保持 60fps（幀時間 < 16.67ms）
- [ ] 無長任務（> 50ms）
- [ ] GPU 占用合理（無過度重排或重繪）

**期望結果**：閃爍動畫應流暢，無卡頓

---

### 場景 C2：prefers-reduced-motion 尊重

1. 在 Chrome 中按 **F12** → **⋮** → **Rendering** → 向下捲動
2. 勾選「Emulate CSS media feature prefers-reduced-motion」
3. 選擇「prefers-reduced-motion: reduce」

**檢查項目**
- [ ] 紅燈閃爍停止
- [ ] 點心保持完全不透明 (opacity: 1)
- [ ] 無脈衝環動畫
- [ ] 所有其他功能正常

**期望結果**：遵守用戶無障礙設定，無動畫

---

## 已知限制與 Phase 6 預告

### 當前 Phase 5 限制

1. **Demo 模式**：異常狀態硬編碼，無真實數據
2. **無按鈕功能**：「確認」和「解決」按鈕尚無後端實現
3. **無異常歷史**：無異常記錄清單或篩選
4. **無通知**：無 WebSocket 實時異常推送

### Phase 6 計畫

1. **後端 API 整合**
   - `/api/admin/devices/[circuit]/anomalies` 取得異常列表
   - `/api/admin/devices/[circuit]/anomalies/[id]/acknowledge` 確認異常
   - `/api/admin/devices/[circuit]/anomalies/[id]/resolve` 解決異常

2. **實時推送**
   - WebSocket 連接接收實時異常
   - 異常計數動態更新

3. **異常歷史**
   - 已解決異常檔案
   - 異常統計儀表板
