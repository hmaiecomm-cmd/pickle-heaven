## Phase 5b 完成內容

### 1. 動畫 CSS 系統 (`src/styles/animations.css`)

**新建檔案**：`src/styles/animations.css`（42 行）

包含：
- `@keyframes blink`：1 秒週期，使用 opacity 1 → 0.3 實現紅燈閃爍效果
- `@keyframes pulse-ring`：2 秒脈衝環擴散效果（嚴重異常警示用）
- `.blink-critical`：套用閃爍動畫的 CSS 類別
- `.pulse-critical`：套用脈衝環動畫的 CSS 類別
- `@media (prefers-reduced-motion: reduce)`：無障礙設定，尊重用戶減少動畫偏好

**WCAG 無障礙合規**：✅ 支持系統減少動畫設定

### CSS 動畫時間參數

| 動畫 | 週期 | 用途 |
|---|---|---|
| blink | 1s | 嚴重異常紅燈閃爍 |
| pulse-ring | 2s | 嚴重異常背景脈衝擴散 |

### 顏色對應

| 狀態 | 背景色 | 文字色 | 點心色 | CSS 類別 |
|---|---|---|---|---|
| 正常 (healthy) | `bg-emerald-50` | `text-emerald-700` | `bg-emerald-500` | — |
| 警告 (warning) | `bg-amber-50` | `text-amber-700` | `bg-amber-500` | — |
| 異常 (error) | `bg-red-50` | `text-red-700` | `bg-red-500` | — |
| 嚴重異常 (critical) | `bg-red-50` | `text-red-700` | `bg-red-600` | `.blink-critical` |
