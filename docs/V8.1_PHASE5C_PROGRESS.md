## UI 視覺構成

### 完整流程

```
用戶選擇迴路 (平面圖或清單)
    ↓
詳情面板 (DetailPanel)
├─ 健康狀態指示欄（頂部）
├─ 迴路名稱和分類
├─ 技術規格
└─ 排程設定按鈕
    ↓
異常詳情面板 (AnomalyPanel) - 如果有異常
├─ 異常計數徽章
├─ 異常列表項
└─ 查看詳情按鈕
```

### 清單項視覺

```
[編號] [設備名稱] [電壓/負載] [● 異常計數 狀態]
```
