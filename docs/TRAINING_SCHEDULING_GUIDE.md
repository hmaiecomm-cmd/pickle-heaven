## 概述

### 🎯 排程功能的作用

排程功能是 Pickle Heaven 智慧場館平台的核心模塊，用於：

- 📅 **管理每日場館時段**（上午、下午、晚間）
- 🎾 **安排迴路使用（球場、設備）**
- 👥 **分配客戶和預約**
- 💰 **自動計算費用**
- 📊 **生成營運報告**

### ✨ 主要特點

✅ 實時時段更新  
✅ 自動衝突檢測  
✅ 智能推薦時間  
✅ 批量排程操作  
✅ 完整審計日誌

## 基本概念

### 🗓️ 時段管理

**時段類型**：

| 時段 | 時間 | 說明 |
|---|---|---|
| **上午** | 06:00-12:00 | 晨練、訓練時段 |
| **下午** | 12:00-18:00 | 主要營業時段 |
| **晚間** | 18:00-22:00 | 夜間活動時段 |
| **特殊** | 彈性 | 特殊活動、賽事 |

**時段狀態**：

```
未排程 → 已排程 → 已確認 → 已完成 → 已結帳
 ⭕      🟡      🟢      ✅      💳
```

### 🎾 迴路（球場/設備）

- **迴路 01-18**：18 條 Pickle Ball 球場
- **設備狀態**：健康/警告/故障/離線
- **可用性**：根據設備健康狀態實時更新
- **預訂限制**：根據時段容量限制

### 👥 客戶類型

| 類型 | 說明 | 優先級 |
|---|---|---|
| **會員** | 年度/季度會員 | 高 |
| **臨時客戶** | 未辦卡客戶 | 中 |
| **教練** | 認證教練 | 高 |
| **群組** | 團隊/公司 | 中 |

## 常見任務

### 📝 任務 1：新增單一排程

**步驟 1**：選擇日期和時段
```
1. 在日期選擇器中選擇日期（或使用日期範圍）
2. 選擇時段：上午 / 下午 / 晚間
3. 點擊「新增排程」按鈕
```

**步驟 2**：填寫排程詳情
```
表單欄位：
├─ 客戶名稱 *（必填）
├─ 迴路編號 *（必填）
├─ 確切時間 *（HH:MM 格式）
├─ 持續時間 *（以分鐘計）
├─ 客戶類型（會員/臨時）
├─ 備註（可選）
└─ 自動計費 ✓（預設啟用）
```

**步驟 3**：確認並保存
```
1. 檢查所有資訊是否正確
2. 確認無時段衝突提示
3. 點擊「保存排程」
4. 系統確認：「排程已成功建立」
```

**範例**：

```
客戶名稱：張先生
迴路：12
日期：2026-11-20
時段：下午（14:00-15:30）
客戶類型：會員
費用：NT$150

✓ 點擊「保存」→ 排程完成
```

### 📝 任務 2：批量排程（群組/公司）

**步驟 1**：選擇批量模式
```
1. 點擊「新增排程」旁的「⋮」菜單
2. 選擇「批量排程」
```

**步驟 2**：設定批量參數
```
批量參數：
├─ 客戶/群組名稱 *
├─ 迴路數量 * (1-18)
├─ 時段 * (上午/下午/晚間)
├─ 日期範圍 * (開始日期 - 結束日期)
├─ 模式：
│  ├─ 逐日（每天相同迴路）
│  ├─ 輪轉（迴路循環）
│  └─ 自訂（手動選擇）
└─ 自動費用計算 ✓
```

**步驟 3**：預覽並確認
```
1. 系統生成預覽表格
2. 檢查迴路分配是否合理
3. 檢查是否有衝突警告
4. 點擊「確認並建立」
```

**範例**：

```
群組名稱：XYZ 公司活動
迴路數量：4
時段：下午
日期：2026-11-20 至 2026-11-22
模式：輪轉

結果：
Day 1: 迴路 01, 02, 03, 04
Day 2: 迴路 05, 06, 07, 08
Day 3: 迴路 09, 10, 11, 12

✓ 確認 → 12 個排程已建立
```

### 📝 任務 3：編輯現有排程

**步驟 1**：定位排程
```
方法 A：日曆檢視
  → 點擊該排程格子 → 彈出詳情

方法 B：列表檢視
  → 搜尋客戶名稱 → 找到排程 → 點擊編輯

方法 C：篩選
  → 使用篩選器 → 縮小結果 → 點擊編輯
```

**步驟 2**：修改內容
```
可編輯欄位：
✓ 迴路編號（如果無衝突）
✓ 確切時間（如果無衝突）
✓ 持續時間（需要重新計費）
✓ 客戶備註
✗ 日期（需要刪除後重新建立）
✗ 客戶（禁止更改以保持審計）
```

**步驟 3**：儲存變更
```
1. 修改完成後點擊「儲存」
2. 系統檢查衝突
3. 如果有衝突提示，選擇解決方案
4. 確認「變更已儲存」
```

### 📝 任務 4：取消/刪除排程

**步驟 1**：定位排程
```
1. 找到要取消的排程（見任務 3 步驟 1）
2. 點擊「⋮」菜單或「編輯」按鈕
```

**步驟 2**：執行取消操作
```
1. 選擇「取消排程」
2. 選擇原因（客戶取消/設備故障/其他）
3. 添加備註（可選）
4. 確認「取消」
```

**步驟 3**：確認結果
```
✓ 排程狀態變更為「已取消」
✓ 自動退款（如適用）
✓ 系統記錄審計日誌
✓ 客戶收到取消通知（如已啟用）
```

## 進階功能

### 🔄 衝突檢測和解決

**自動衝突檢測**：

當您嘗試建立/修改排程時，系統會自動檢查：
- ⚠️ 同一迴路、同一時間是否已有排程
- ⚠️ 設備健康狀態（故障/離線設備）
- ⚠️ 時段容量限制（最多 18 迴路）

**衝突解決方案**：

```
衝突提示：迴路 12 下午 14:00-15:30 已被預訂

解決方案：
  1️⃣ 選擇其他迴路（推薦空閒迴路）
  2️⃣ 更改時間（推薦替代時間）
  3️⃣ 選擇其他日期
  4️⃣ 放在候補名單（如適用）
```

### 📊 智能推薦系統

**場景**：客戶想要預訂但首選時段已滿

**推薦工作流程**：

```
客戶選擇：迴路 12，下午，2026-11-20

系統檢查 → 衝突 → 自動推薦

推薦選項（優先順序）：
  1️⃣ 迴路 15-18（同時段空閒）- 最佳
  2️⃣ 下午 16:00-17:30（同迴路稍後）
  3️⃣ 2026-11-21 下午（次日同時段）
  4️⃣ 晚間 18:00-19:30（同日較晚）

客戶可以：
  ✓ 接受推薦
  ✓ 進一步自訂
  ✓ 放入候補名單
```

## 故障排查

### ❓ 常見問題

#### Q1: 為什麼無法建立排程？

**可能原因和解決方案**：

```
原因 1：迴路已被預訂
  → 查看其他迴路或時間
  → 或等待現有預訂取消

原因 2：設備故障/離線
  → 檢查設備健康狀態
  → 聯絡技術支援
  → 等待設備恢復

原因 3：超過容量限制
  → 檢查是否超過 18 迴路限制
  → 分割為多個時段

原因 4：時間無效
  → 確認時間格式（HH:MM）
  → 確認持續時間 > 0
  → 確認在營業時間內
```

#### Q2: 排程未出現在日曆上？

**檢查清單**：

```
□ 確認日期是否正確
□ 確認是否勾選了對應的時段篩選
□ 清除瀏覽器快取（Ctrl+Shift+Delete）
□ 重新整理頁面（F5）
□ 檢查排程狀態（可能是草稿）
```

#### Q3: 費用計算不正確？

**驗證步驟**：

```
1. 確認客戶類型：
   ├─ 會員 → 會員價格適用
   └─ 臨時 → 標準價格適用

2. 確認時間計算：
   ├─ 持續時間正確
   └─ 不含折扣或特殊優惠

3. 檢查特殊費用：
   ├─ 高峰時段加價？
   ├─ 群組折扣？
   └─ 季節性調整？

4. 如果仍不對 → 聯絡會計部門
```

#### Q4: 無法編輯排程？

**可能原因**：

```
✗ 排程已完成（已結帳）
  → 無法編輯已完成排程
  → 需要建立新排程

✗ 排程已有衝突
  → 解決衝突後再編輯
  → 或取消後重新建立

✗ 權限不足
  → 檢查您的使用者角色
  → 聯絡管理員提升權限

✗ 系統維護中
  → 等待維護完成
  → 稍後重試
```
