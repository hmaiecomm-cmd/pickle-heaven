# 功能差異清單（2026-10-07）

盤點對象：前台「大新店森林匹克球」、後台「匹克精靈」。基準：commit 54e9d92（人員管理已提交、待正式部署）。
狀態定義：**已完成** = 真實資料庫邏輯 + 可操作畫面；**部分完成** = 只有畫面、展示資料、唯讀或占位文字；**缺少** = 沒有程式；**待外部串接** = 程式有但需要憑證／硬體／服務商。
「驗證依據」為實際檔案與行為；之前對話提過的功能不直接視為完成。

## 10. 實作順序（依新指令）

1. **第一階段**：權限與資料隔離（本清單 R2–R4、R6、第 2 節）、登入、場地一致性、網址變數統一、sitemap。
2. **第二階段**：儲值方案與流程（依 R1 決定）、票券生命週期與結帳抵扣、價格設定、商城與商品訂單、行事曆週／月視圖。
3. **第三階段**：整期課程、會員權益等級與特例、回流工具、候補模式、費用拍照登錄與審核。
4. **第四階段**：營運分析（非財務／財務分區、明細、匯出、對帳、口徑標示）。
5. **第五階段**：自動化規則與排程、通知發送、設備串接介面。

每階段：完成 → 測試 → 部署既有 Vercel 正式站 → 線上檢查 → 回報（補齊項目、驗證流程、查看路徑、待設定項目、版本與回復方式）。
