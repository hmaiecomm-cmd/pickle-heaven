## 概述

### 🎯 權限系統的作用

權限管理系統控制誰可以做什麼：

- 🔐 **存取控制**：確保只有授權人員可以訪問特定功能
- 👥 **角色管理**：分配用戶角色和對應權限
- 📋 **數據保護**：限制敏感數據訪問
- 📊 **操作審計**：記錄所有用戶操作
- 🔒 **安全合規**：符合數據保護法規

### ✨ 主要特點

✅ 基於角色的訪問控制（RBAC）  
✅ 靈活的權限分配  
✅ 實時權限生效  
✅ 完整的審計追蹤  
✅ 批量用戶管理

## 用戶角色

系統定義了 5 個主要角色，層級從高到低：

### 1️⃣ 超級管理員（System Administrator）

**職責**：系統最高權限持有者

**權限**：
```
✓ 系統設定和配置
✓ 用戶和角色管理
✓ 數據庫備份和恢復
✓ 安全性設定
✓ 日誌審計
✓ 所有模塊完全訪問
```

**數量限制**：最多 2 人（建議）  
**責任**：系統安全、數據保護

**日常任務**：
- 建立/刪除用戶帳戶
- 分配角色和權限
- 管理安全策略
- 監控系統性能
- 處理安全事件

---

## 管理用戶

### 👤 新增用戶

**位置**：管理面板 → 用戶管理 → 新增用戶

**步驟 1**：填寫基本信息

```
必填字段：
├─ 用戶名 * (唯一，3-20 個字符)
├─ 郵箱地址 * (用於登錄和通知)
├─ 真實姓名 *
├─ 電話號碼 * (用於聯絡)
└─ 部門 * (選擇部門)

選填字段：
├─ 職位
├─ 員工 ID
├─ 辦公地點
└─ 個人備註
```

**步驟 2**：設定密碼

```
選項 A：系統生成密碼
  → 系統自動生成複雜密碼
  → 通過郵件發送給用戶
  → 用戶首次登錄時更改

選項 B：管理員設定
  → 管理員輸入臨時密碼
  → 用戶首次登錄時更改
  → 建議：確保密碼符合複雜度要求
```

**步驟 3**：分配角色

```
1. 選擇主角色（只能一個）
   └─ 超級管理員 / 經理 / 前台 / 維護 / 客戶

2. 可選：分配額外權限
   └─ 特定功能或模塊的額外訪問

3. 設定生效日期（可選）
   └─ 立即生效 或 指定日期
```

**步驟 4**：審核和確認

```
審查清單：
□ 用戶名正確且唯一
□ 郵箱地址有效
□ 角色設定合適
□ 權限分配正確
□ 所有必填字段已完成

點擊「創建用戶」
```

**系統確認**：
```
✓ 新用戶帳戶已創建
✓ 通知郵件已發送
✓ 權限設定已生效
✓ 審計日誌已記錄
```

### 🔐 重置密碼

**情景 1**：用戶忘記密碼

```
過程：
1. 用戶點擊登錄頁面的「忘記密碼」
2. 輸入郵箱地址
3. 系統發送重置鏈接
4. 用戶通過郵件中的鏈接重設密碼
5. 新密碼立即生效
```

**情景 2**：管理員重置用戶密碼

```
步驟：
1. 管理面板 → 用戶管理
2. 找到用戶 → 點擊「⋮」菜單
3. 選擇「重置密碼」
4. 選擇重置方式：
   ├─ 系統發送重置郵件（推薦）
   └─ 管理員直接設定臨時密碼
5. 通知用戶已重置
```

### 🚫 禁用/刪除用戶

**禁用用戶**（推薦）

```
何時使用：
• 用戶離職或休假
• 暫時限制訪問
• 等待人事確認

步驟：
1. 用戶管理 → 選擇用戶
2. 點擊「更多選項」
3. 選擇「禁用帳戶」
4. 選擇禁用原因
5. 添加備註
6. 確認禁用

效果：
✓ 用戶無法登錄
✓ 現有會話被終止
✓ 權限立即撤銷
✓ 審計日誌記錄
```

**刪除用戶**（謹慎使用）

```
注意：刪除是永久性操作

何時使用：
• 清理測試帳戶
• 符合 GDPR 要求（被遺忘權）
• 數據清理

步驟：
1. 確認要刪除的用戶
2. 備份相關數據
3. 用戶管理 → 選擇用戶
4. 點擊「刪除用戶」
5. 二次確認
6. 輸入驗證碼

效果：
✓ 帳戶永久刪除
✓ 相關數據清除（根據政策）
✓ 操作無法撤銷
✓ 審計日誌記錄
```

**步驟 1**：定義基本信息

```
├─ 角色名稱 *（唯一）
├─ 描述 *（用途說明）
├─ 基於模板 （可選）
│  └─ 以現有角色為基礎
└─ 優先級 （系統內部使用）
```

**步驟 2**：分配權限

```
按模塊分配權限：

□ 排程管理
  □ 查看
  □ 建立
  □ 編輯
  □ 刪除
  □ 批量操作

□ 預約管理
  □ 查看
  □ 建立
  □ 編輯
  □ 取消
  □ 退款

□ 客戶管理
  □ 查看
  □ 編輯
  □ 刪除
  □ 通信

□ 設備管理
  □ 查看
  □ 報告
  □ 維護標記
  □ 配置

□ 財務
  □ 查看報表
  □ 編輯價格
  □ 導出
  □ 發票

□ 系統
  □ 用戶管理
  □ 角色管理
  □ 安全設定
  □ 審計日誌
```

**步驟 3**：數據訪問限制

```
設定數據訪問級別：

訪問級別 1：全部數據
  → 可訪問所有客戶、預約等數據

訪問級別 2：部門數據
  → 只能訪問同部門的數據

訪問級別 3：自己的數據
  → 只能訪問自己建立的記錄

訪問級別 4：無訪問
  → 無任何數據訪問權限
```

**步驟 4**：審核和確認

```
審查清單：
□ 角色名稱清晰
□ 權限分配完整
□ 無相互衝突的權限
□ 符合最小權限原則

點擊「創建角色」
```

## 安全性

### 🔒 密碼策略

系統強制執行的密碼要求：

| 要求 | 標準 |
|---|---|
| 最小長度 | 12 個字符 |
| 大小寫混合 | 必須包含大小寫字母 |
| 數字 | 必須包含至少 1 個數字 |
| 特殊字符 | 必須包含特殊字符（!@#$%^&*） |
| 密碼過期 | 90 天（可配置） |
| 歷史檢查 | 不能重用最近 5 個密碼 |
| 登錄嘗試 | 5 次失敗後鎖定 30 分鐘 |

**範例有效密碼**：
```
✓ MyPassword123!@# (16 字符)
✓ Secure_2026_Pass99
✓ Gr8P@ssw0rd!

✗ password123 (無大寫)
✗ PassWord (無特殊字符)
✗ Pass1! (太短)
```

### 🔐 雙因素認證（2FA）

**啟用 2FA**：

```
步驟：
1. 用戶設定 → 安全性
2. 點擊「啟用雙因素認證」
3. 掃描 QR 碼（使用 Google Authenticator）
4. 輸入 6 位驗證碼確認
5. 保存備份碼（用於恢復）

此後每次登錄需要：
├─ 用戶名和密碼
└─ 手機應用中的 6 位驗證碼
```

**建議**：
- 強制要求管理員使用 2FA
- 強烈建議其他用戶啟用 2FA

### 🛡️ 會話管理

| 設定 | 值 |
|---|---|
| 會話超時 | 30 分鐘無活動自動登出 |
| 最大會話數 | 用戶最多 3 個並發會話 |
| 會話令牌 | 每 15 分鐘刷新一次 |
| 登出後 | 會話立即作廢 |

---

### 🚨 安全事件

**可疑活動警告**：

系統會在以下情況發送警告：

```
⚠️ 登錄失敗 5 次
  → 帳戶鎖定 30 分鐘
  → 管理員收到通知

⚠️ 異常登錄地點
  → 發送確認郵件
  → 用戶需要驗證

⚠️ 大量數據導出
  → 記錄操作
  → 管理員審查

⚠️ 權限提升操作
  → 發送確認郵件
  → 要求 2FA 驗證

⚠️ 帳戶被禁用
  → 用戶無法登錄
  → 現有會話被終止
```

```
1. 用戶活動報告
```

## 常見問題

### Q1: 如何為新員工快速分配權限？

```
使用角色模板：
1. 選擇相似的現有角色
2. 複製為新角色
3. 根據需要微調權限
4. 為新員工分配此角色
5. 監控並根據反饋調整

時間節省：10 分鐘 vs 30 分鐘
```

### Q2: 如何處理權限爭議？

```
解決流程：
1. 查看審計日誌確認操作
2. 檢查用戶的角色和權限
3. 與經理確認是否授權
4. 根據結果採取行動：
   ├─ 如果未授權 → 禁用用戶
   ├─ 如果授權但錯誤 → 更改權限
   └─ 如果疑似黑客 → 啟動安全事件流程
5. 記錄事件和解決方案
```

### Q3: 為什麼用戶無法訪問某個功能？

```
檢查清單：
□ 用戶帳戶已啟用？
□ 用戶角色是否有此功能權限？
□ 權限生效日期已到達？
□ 用戶會話是否仍有效？
□ 瀏覽器快取是否需要清除？
□ 是否需要重新登錄？

解決步驟：
1. 檢查用戶的角色和權限
2. 對比權限矩陣
3. 如需修改，編輯用戶角色
4. 通知用戶重新登錄
5. 測試訪問是否恢復
```
