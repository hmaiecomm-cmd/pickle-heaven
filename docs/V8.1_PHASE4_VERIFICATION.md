## 互動流程驗證

### 流程 A：平面圖選取 → 詳情更新 → 清單同步

```
1. 用戶點擊平面圖上的迴路（例如 01）
   ↓
2. FloorPlan 調用 onSelect({ type: 'circuit', id: '01' })
   ↓
3. DeviceManager 的 setSelected 更新狀態
   ↓
4. DetailPanel 顯示迴路 01 的詳情
   ↓
5. CircuitList 中迴路 01 的行背景變綠
```

**驗收**：✅ 完整同步（代碼第 69-75、89、95、99 行）

### 流程 B：清單選取 → 平面圖更新 → 詳情更新 → 自動捲動

```
1. 用戶點擊清單中的迴路行（例如 05）
   ↓
2. CircuitList 調用 selectFromList({ type: 'circuit', id: '05' })
   ↓
3. selectFromList 更新 setSelected 並觸發自動捲動
   ↓
4. DetailPanel 顯示迴路 05 的詳情
   ↓
5. FloorPlan 中迴路 05 周圍顯示高亮圓圈
   ↓
6. 詳情面板自動捲動到可見位置
```

**驗收**：✅ 完整同步，包含自動捲動（代碼第 72-75 行）

### 流程 C：位置標記選取

```
1. 用戶點擊平面圖上的位置標記
   ↓
2. FloorPlan 調用 onSelect({ type: 'marker', id: 'xxx' })
   ↓
3. DetailPanel 顯示位置標記詳情（非控制設備）
```

**驗收**：✅ 完整實現（代碼第 137-154 行）
