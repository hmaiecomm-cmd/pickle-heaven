## 🎯 如何使用這些文檔

### 場景 1：新員工入職

**第一天**：
1. 閱讀本索引文檔（10 分鐘）
2. 瀏覽 TRAINING_PERMISSIONS_GUIDE.md 了解角色（20 分鐘）
3. 開始 TRAINING_SCHEDULING_GUIDE.md 基本概念（30 分鐘）

**第一週**：
1. 完成 TRAINING_SCHEDULING_GUIDE.md 常見任務章節（3 小時）
2. 在導師指導下實踐排程操作（2-3 小時）
3. 收藏 TRAINING_FAQ.md 作為參考（隨時查詢）

**第二週及之後**：
1. 根據需要查詢進階功能（TRAINING_SCHEDULING_GUIDE.md）
2. 遇到問題時參考 FAQ（TRAINING_FAQ.md）
3. 逐漸達到獨立操作水平

### 場景 2：系統管理員接手

**入職準備**：
1. 完整閱讀 TRAINING_PERMISSIONS_GUIDE.md（2-3 小時）
2. 瀏覽 TRAINING_SCHEDULING_GUIDE.md 的進階功能章節（1 小時）
3. 熟悉 TRAINING_FAQ.md 的各分類（1 小時）

**實踐階段**：
1. 根據公司需要配置用戶角色（1-2 天）
2. 建立用戶管理流程（3-5 天）
3. 設定安全策略和監控（1-2 週）

### 場景 3：快速查詢特定問題

1. 打開 TRAINING_FAQ.md
2. 使用 Ctrl+F 搜尋關鍵字
3. 找到對應問題和答案
4. 按照步驟操作

### 場景 4：深入學習某功能

1. 確定功能所在文檔
2. 找到對應章節
3. 逐步閱讀並理解
4. 在實際系統中練習
5. 參考 FAQ 解決遇到的問題

## 💡 使用技巧

### 1. 有效搜尋

```
在 Markdown 編輯器或瀏覽器中使用 Ctrl+F 搜尋：
• 搜尋步驟：「步驟」
• 搜尋範例：「範例」
• 搜尋錯誤：「錯誤」或「故障」
• 搜尋表格：「表」或「|」
```

### 2. 打印友善

```
所有文檔都可打印為 PDF：
1. 用瀏覽器打開 .md 文檔
2. 右鍵 → 打印
3. 選擇「另存為 PDF」
4. 存到您的設備
```

### 3. 書籤和註記

```
建議在重要位置添加書籤：
• 常見任務步驟
• 權限矩陣
• 常見錯誤
• 聯絡信息
```

### 4. 離線訪問

```
下載所有三份文檔供離線查詢：
1. GitHub 上 docs/ 文件夾
2. 下載所有 TRAINING_*.md 文件
3. 用任何 Markdown 編輯器打開
4. 或轉換為 PDF 儲存
```
