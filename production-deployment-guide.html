1

建立生產 Turso 資料庫

目標：在 Turso 平台建立專屬的生產資料庫

1.1 訪問 Turso 官網

  1. 打開瀏覽器，訪問 https://turso.tech
  2. 登入您的 Turso 帳戶（使用 GitHub / Google 帳號）
  3. 進入儀表板（Dashboard）

1.2 建立新資料庫

  1. 點擊 「Create Database」 按鈕
  2. 填入資料庫名稱：pickle-heaven-prod
  3. 選擇地區：
    • 推薦： ap-northeast-1（東京 - 台灣最近）
    • 備選： ap-singapore（新加坡）
  4. 點擊 「Create」 確認建立
💡 建立過程通常需要 10-30 秒。頁面會自動重新整理。

1.3 取得連線資訊

  1. 建立完成後，進入新資料庫頁面
  2. 點擊 「Connect」 按鈕
  3. 複製以下資訊（稍後需要用到）：
    • Database URL
    • Auth Token
✓ 完成標記：您已獲得資料庫連線資訊，可進行下一步
2

配置 Vercel 環境變數

目標：將 Turso 連線資訊輸入 Vercel，供應用使用

2.1 訪問 Vercel 儀表板

  1. 打開 https://vercel.com
  2. 登入您的 Vercel 帳戶
  3. 找到 pickle-heaven 專案

2.2 進入專案設定

  1. 點擊專案名稱進入專案頁面
  2. 導航到 Settings（設定）標籤
  3. 在左側選單中，選擇 Environment Variables

2.3 新增環境變數

需要新增 2 個環境變數。點擊 「Add New」 按鈕，逐個添加：

變數 1：
Name: TURSO_DATABASE_URL Value: libsql://pickle-heaven-prod-XXXXX.turso.io

（用 Turso 給您的 URL 替換 XXXXX 部分）

變數 2：
Name: TURSO_AUTH_TOKEN Value: <粘貼您從 Turso 複製的 Token>

2.4 環境確認

確保您新增的變數應用於：

  • ✓ Production
  • ✓ Preview
  • ✓ Development
⚠️ 重要：變數配置完成後不要急著關閉頁面，等待 Vercel 顯示「Saved」確認。
✓ 完成標記：環境變數已在 Vercel 成功配置
3

執行生產遷移

目標：將資料庫 schema 同步到生產環境

3.1 觸發自動遷移（推薦）

Vercel 會在部署時自動執行遷移。只需等待下次部署完成：

  1. 進入 Vercel 專案的 Deployments 標籤
  2. 找到最新的部署（通常在列表頂部）
  3. 等待狀態顯示 Ready（綠色）
  4. 此時遷移已自動執行

3.2 手動遷移（可選備份）

如果您想在本機確認遷移，可以手動執行：

  1. 在電腦上打開終端機（Terminal / CMD）
  2. 進入專案目錄：
    cd 「您的專案路徑」
  3. 執行遷移命令：
    DATABASE_URL="libsql://pickle-heaven-prod-XXXXX.turso.io" \ TURSO_AUTH_TOKEN="您的Token" \ npx prisma migrate deploy
  4. 等待命令完成。成功輸出應該是：
    All migrations have been successfully applied.
⚠️ 注意：遷移是一次性操作。執行後無法撤銷，但不會重複執行相同遷移。
✓ 完成標記：看到「All migrations have been successfully applied」
4

驗證線上 API

目標：確認應用能夠正常連接到生產資料庫

4.1 訪問應用首頁

  1. 訪問 https://pickle-heaven.vercel.app
  2. 確認前台頁面正常加載
  3. 檢查是否有任何錯誤訊息

4.2 測試後台登入

  1. 訪問 https://pickle-heaven.vercel.app/admin
  2. 使用 Demo 帳號登入：
    • 帳號： admin
    • 密碼： 12345678
  3. 成功登入後，瀏覽幾個頁面確認功能正常

4.3 驗證 API 連接

打開瀏覽器的開發者工具（F12），進行以下測試：

測試自動化規則 API：
curl https://pickle-heaven.vercel.app/api/admin/automation/rules 預期回應： { "rules": [] }
測試排程 API：
curl https://pickle-heaven.vercel.app/api/admin/circuits/schedule?circuitNumber=01 預期回應： { "id": "...", "schedules": [] }

4.4 檢查清單

  • 前台首頁加載正常
  • 後台能成功登入
  • 後台六宮格首頁顯示
  • 設備管理頁面可以訪問
  • 排程管理功能可用
  • API 返回正確的 JSON 回應
✓ 完成標記：所有檢查項目都通過，系統已成功上線！

🎉 恭喜！生產部署完成

您的系統現在已經完全上線運作。

後續建議

  • 立即修改 Demo 密碼：登入後立刻將 admin 密碼改為強密碼
  • 監控 Vercel：定期檢查 Vercel 儀表板確保部署穩定
  • 檢查日誌：在 Vercel → Functions → Logs 查看 Cron 任務運行日誌
  • 備份資料庫：定期在 Turso 儀表板備份資料庫
