## 📱 手機連接方法

### 方法 A：網址直接連接（推薦）

```
步驟：
1. 在手機瀏覽器地址欄輸入：
   http://192.168.x.x:8080
   
2. 替換 x.x 為你的 PC 本地 IP（如 192.168.1.100）

3. 按 Enter 訪問

4. 等待 2-3 秒加載，即可看到控制界面
```

### 方法 B：二維碼掃描

```
步驟：
1. 在 PowerShell 中選擇 [6] 查看 QR Code

2. 打開 QUICK_CONNECT_QR.html 文件

3. 用手機相機應用掃描二維碼

4. 點擊出現的連結，自動打開系統

5. 無需手動輸入 IP 地址和埠號
```

### 方法 C：WiFi 共享（局域網內所有設備）

```
如果你有多部手機或平板需要連接：

1. 確保所有設備都連接到同一 WiFi 網絡

2. 在每部設備上輸入相同的 URL：
   http://192.168.x.x:8080

3. 支援同時連接多個設備
```

## 📡 本地 IP 地址查詢

### Windows 系統中查詢

**方法 1：通過 PowerShell**
```powershell
Get-NetIPAddress -AddressFamily IPv4 | Where-Object {$_.IPAddress -ne "127.0.0.1"}
```

**方法 2：通過命令提示符**
```cmd
ipconfig /all
```

**方法 3：通過 PowerShell 遠程管理工具**
- 選擇 **[9] 系統設置**
- 會顯示「本地 IP」

### 典型的本地 IP 格式

```
192.168.0.x    (路由器分配)
192.168.1.x    (路由器分配)
10.0.0.x       (企業網絡)
172.16.x.x     (專業網絡)
```

## 🛠️ 故障排查

### 問題 1：無法連接到 Web 伺服器

**症狀**：瀏覽器顯示「無法連接」或「連接超時」

**解決方案**：
```powershell
# 1. 檢查 PowerShell 中是否已啟動 Web 伺服器
#    選擇 [7] 應該看到 "Web 伺服器已啟動" 的消息

# 2. 檢查 IP 地址是否正確
#    在 PowerShell 中選擇 [9] 查看「本地 IP」

# 3. 檢查 WiFi 連接
#    確保手機和 PC 在同一 WiFi 網絡

# 4. 檢查防火牆設置
# 允許 PowerShell 通過防火牆：
# 控制面板 → Windows Defender 防火牆 → 允許應用通過防火牆
```

### 問題 2：二維碼無法生成

**症狀**：選擇 [6] 但沒有看到二維碼文件

**解決方案**：
```powershell
# 檢查文件是否存在
Test-Path "C:\Users\hmai.ecomm\Dropbox\顧好AI智慧場館平台\iot\controllers\QUICK_CONNECT_QR.html"

# 如果返回 False，文件可能缺失
# 重新下載或複製 QUICK_CONNECT_QR.html
```

### 問題 3：手機掃碼後無反應

**症狀**：掃碼後點擊連結沒有打開頁面

**解決方案**：
1. 檢查手機上 WiFi 是否正確連接
2. 嘗試手動輸入 URL：`http://192.168.1.100:8080`
3. 確認 PowerShell 中 Web 伺服器仍在運行
4. 清除手機瀏覽器快取並重試

### 問題 4：實時監控面板不更新

**症狀**：監控面板卡在同一時間戳

**解決方案**：
```powershell
# 1. 按 Ctrl+C 退出監控
# 2. 重新選擇 [2] 重啟監控
# 3. 確認 PowerShell 窗口處於活躍狀態
```

## 🎯 進階用法

### 通過命令行快速啟動特定功能

```powershell
# 直接啟動監控面板
& "C:\...\REMOTE_MANAGEMENT.ps1" -Action monitor

# 直接啟動 Web 伺服器
& "C:\...\REMOTE_MANAGEMENT.ps1" -Action web

# 查看系統狀態
& "C:\...\REMOTE_MANAGEMENT.ps1" -Action status

# 顯示 QR Code
& "C:\...\REMOTE_MANAGEMENT.ps1" -Action qr
```

### 設置 Windows 任務排程器自動啟動

```powershell
# 創建自動啟動腳本
$taskAction = New-ScheduledTaskAction `
  -Execute "PowerShell.exe" `
  -Argument "-ExecutionPolicy Bypass -File C:\...\REMOTE_MANAGEMENT.ps1"

$taskTrigger = New-ScheduledTaskTrigger -AtLogOn

Register-ScheduledTask -Action $taskAction -Trigger $taskTrigger `
  -TaskName "SmartVenueMgmt" -Description "匹克天堂遠程管理"
```
