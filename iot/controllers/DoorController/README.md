## 🎯 系統功能

### 核心功能
- ✅ 門禁卡刷卡識別
- ✅ 人臉識別集成（可選）
- ✅ PIN 碼輸入驗證
- ✅ 實時門禁狀態監控
- ✅ 訪客管理與黑名單
- ✅ 審計日誌與追蹤
- ✅ 應急開門與緊急鎖定

### 12 步自動化流程
1. 訪客刷卡 → 卡號識別
2. 系統查詢訪客信息
3. 驗證訪客身份與權限
4. 生成進場記錄
5. 觸發門禁開啟
6. 記錄進場時間
7. 監控人員通過
8. 驗證離場（如需）
9. 生成離場記錄
10. 更新訪客統計
11. 生成審計日誌
12. 同步雲端系統

## 📡 MQTT 命令

### 開門命令
```json
{
  "action": "open_door",
  "door_id": "entrance_01",
  "reason": "admin",
  "expires_at": "2026-11-12T10:05:00Z"
}
```

### 查詢訪客
```json
{
  "action": "query_visitor",
  "visitor_id": "CARD_12345678",
  "check_blacklist": true
}
```

### 緊急鎖定
```json
{
  "action": "emergency_lock",
  "all_doors": true,
  "reason": "security_alert"
}
```
